# Privacy Policy

Full Path for Google Drive™ (the "extension")

Effective date: November 14, 2026

## Summary

The extension does not collect, transmit, sell, or share any user data. Everything it reads stays in your browser.

## Data the extension reads

- The names and IDs of the folders in the breadcrumb of the Google Drive™ page you have open, including the folders Google Drive hides behind "...".
- The path of the current page URL, to find the ID of the open folder and the account number (`/u/N/`) used when moving to a folder.

This data is used only to show the full folder path in the breadcrumb and in the extension's popup, to move to a folder you click, and to build the path you copy. It is kept in memory only while the page is open and is never saved or sent anywhere.

## Data the extension stores

- The settings you enter on the options page: the text to prepend to the copied path and the folder separator.

The settings are saved with `chrome.storage.local` on your device only. Removing the extension deletes them.

## Clipboard

The extension writes the folder path to the clipboard only when you click the copy button. It never reads the clipboard.

## Sharing and transmission

The extension makes no network requests. It does not use analytics, advertising, or any third-party service, and no person, including the developer, can see your data.

## Permissions

- `storage`: to save the copy settings on your device.
- Access to `https://drive.google.com/*`: to read the breadcrumb on Google Drive pages.

## Limited Use

The use of user data by the extension complies with the [Chrome Web Store User Data Policy](https://developer.chrome.com/docs/webstore/program-policies/policies), including the Limited Use requirements.

## Changes

If this policy changes, the new version will be posted on this page with a new effective date.

## Contact

Please open an issue at <https://github.com/moyashimegane/drive-full-path/issues>.

Google Drive is a trademark of Google LLC.

# プライバシーポリシー

Full Path for Google Drive™（以下「この拡張機能」）

施行日：2026年11月14日

## 概要

この拡張機能は、利用者のデータを集めることも、送ることも、売ることも、共有することもしません。読み取った内容はすべてブラウザの中だけで使います。

## 読み取るデータ

- 開いているGoogleドライブ™のページのパンくずにあるフォルダの名前とID（「...」に隠れているフォルダも含みます）。
- 開いているフォルダのIDと、フォルダを移動するときに使うアカウント番号（`/u/N/`）を知るための、ページのURLのパス。

これらは、パンくずとポップアップにフルパスを表示すること、クリックしたフォルダへ移動すること、コピーするパスを作ることにだけ使います。ページを開いている間だけメモリに置き、保存も送信もしません。

## 保存するデータ

- オプション画面で入力した設定（コピーするパスの先頭に付ける文字と、フォルダの区切り文字）。

設定は`chrome.storage.local`で、利用者の端末の中にだけ保存します。この拡張機能を削除すると設定も消えます。

## クリップボード

コピーのボタンを押したときだけ、フォルダのパスをクリップボードに書き込みます。クリップボードの中身を読むことはありません。

## 共有と送信

この拡張機能は通信を一切しません。アクセス解析、広告、外部のサービスは使っておらず、開発者を含めて誰も利用者のデータを見ることはできません。

## 権限

- `storage`：コピーの設定を端末に保存するため。
- `https://drive.google.com/*`へのアクセス：Googleドライブのページのパンくずを読み取るため。

## Limited Use（利用の制限）

この拡張機能による利用者データの扱いは、[Chrome Web Store User Data Policy](https://developer.chrome.com/docs/webstore/program-policies/policies)（Limited Useの要件を含む）に従います。

## 変更

このポリシーを変えるときは、新しい施行日とともにこのページに載せます。

<https://github.com/moyashimegane/drive-full-path/issues>にissueを作成してください。
